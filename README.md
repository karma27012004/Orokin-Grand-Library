# Welcome to the Orokin Grand Library

Here you'll find crucial information related to the game "Warframe".

Application is designed with python, to run type on terminal:

```
python ./main.py
```
While inside the directory

## Features:

### Current:

- [x] Information about warframes and how to obtain them
- [x] Information about relics and where to obtain them

### Planned: 

- [] Build planner and calculator
- [] Weapon browser
- [] Resource farm helper
- [] Lore
- [] .exe for easy opening
- [] Better and prettier UI
- [] And more!

### Not planned (but possible):

- [] Node details
- [] Open world stuff


## Dependencies:

```
pip install pillow
```

This program uses 'pillow' to load images

On some linux distros, 'tkinter' is packaged separately:

```
sudo apt install python-tk
```

## Libraries:

- tkinter: UI
- json: Store information
- urlib.request: Download images
